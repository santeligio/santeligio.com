# AGENTS.md

This file provides guidance to AI coding agents when working with code in this repository.

## Project overview

Static site for the Compagnia di Sant'Eligio (a historical association in Vernante, Italy), built with
[Astro](https://astro.build) and Markdown content collections, hosted on Netlify. Site content is in Italian
(`SITE.lang = 'it'` in `src/consts.ts`). This is a rebuild of a previous Gatsby site — legacy URLs are preserved
via Netlify redirects.

## Commands

Requires Node.js >= 20.9.0.

```sh
npm install
npm run dev       # local dev server
npm run build     # build to dist/
npm run preview   # preview the production build
```

There is no test suite and no local lint script in `package.json`. Linting runs in CI only, via GitHub Actions
(`.github/workflows/super-linter.yml`), using `super-linter/super-linter` on push/PR to `main`.

## Architecture

- **Routing**: file-based, under `src/pages/`. `src/pages/news/[...slug].astro` is the one dynamic route — it
  calls `getStaticPaths()` over the `news` content collection (filtering out `draft: true` entries) and renders
  each post via `getCollection`/`render` from `astro:content`.
- **Content collections**: defined in `src/content.config.ts`. The `news` collection loads Markdown from
  `src/content/news/*.md` (frontmatter: `title`, `description?`, `date`, `cover?`, `coverAlt?`,
  `category` default `"storia"`, `draft` default `false`). This collection is the site's "news"/"novità" section
  (formerly the Gatsby blog).
- **Layout**: `src/layouts/Base.astro` is the single shared HTML shell — head/meta/OG tags, canonical URL,
  sitemap link, and `Header`/`TranslationHint`/`Footer` wrapping a `<slot />`. Every page composes itself as
  `<Base>...</Base>` plus components from `src/components/`.
- **Site constants**: `src/consts.ts` holds `SITE` (URL, title, description, lang, email) and `NAV` (the header
  nav items) — update these rather than hardcoding site metadata elsewhere.
- **Styling**: Tailwind CSS v4 via the `@tailwindcss/vite` plugin (no `tailwind.config.*` — v4 is configured in
  CSS). Theme tokens (fonts, colors) are declared with `@theme` in `src/styles/global.css`: a historical-society
  palette (`ink`, `wine`, `gold`, `parchment`). Base element styles live in `@layer base` deliberately, so
  Tailwind utility classes can still override them (unlayered CSS otherwise always wins over layered CSS).
  Rendered Markdown content is styled via the `.prose-eligio` class (not `@tailwindcss/typography`).
- **Analytics**: Cloudflare Web Analytics only (no Google Analytics), injected in `Base.astro` conditionally on
  `import.meta.env.PUBLIC_CLOUDFLARE_BEACON_TOKEN` — the beacon script is absent from builds where that env var
  isn't set (e.g. local dev), keeping dev analytics-free.
- **Redirects**: legacy Gatsby-site URLs are redirected via `public/_redirects` (Netlify's redirect file format,
  real HTTP 301s) rather than Astro-generated meta-refresh pages, since hosting stays on Netlify — see the
  comment in `astro.config.mjs`.
- **Sitemap**: generated by the `@astrojs/sitemap` integration (configured in `astro.config.mjs`).
- **Deployment**: Netlify, config in `netlify.toml` (`npm run build`, publish `dist/`, Node 20).

## Content editing notes

- New news posts: add a `.md` file under `src/content/news/` with `title`, `date`, and `category` frontmatter.
- **Privacy rule** (from readme): historical/archival material is publishable; living members are named only
  with their consent. Keep this in mind when adding or editing content that names people.
- Static assets (images, `_redirects`, `_headers`) live under `public/`.
